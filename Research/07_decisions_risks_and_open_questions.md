# 当前判断、风险与未决问题

## 1. 已形成的主判断

### D1：保留 L0，但把它定义成项目交付级别

内部阶段只用 P0–P10。任何 connector-only 文档都不得再单独称 L0。

### D2：SOTA 用同档 Pareto 前沿定义

必须绑定模型/训练/推理预算和能力集合；不追一个失去上下文的总榜单。

### D3：方法主路线是“强初始化 + 全参数联合训练 + 完整后训练”

冻结骨干/PEFT 是成本或快速实验路线，不是默认上限论证。原生 early-joint 是重要前沿分支，等待目标规模验证。

### D4：把视觉编码器作为独立能力瓶颈

OCR、grounding、时序和高分辨率信息若未进入视觉 token，LLM/connector 无法凭空恢复。

### D5：视觉 token 预算与能力一起优化

所有架构比较都应画能力-视觉 token-时延曲线，避免用无限 token 假装编码效率提升。

### D6：纯文本 replay 与文本回归是完整 L0 的硬约束

多模态能力增长不能以语言、代码和数学能力无上限退化为代价。

### D7：数据工程与损失权重同等重要

样本比例不等于梯度比例。长 caption、视频、短 VQA 和纯文本必须同时在 sampling 与 loss normalization 层受控。

### D8：推理能力采用“冷启动/蒸馏 → 离线偏好 → 在线 RL”

在线 RL 优先使用可验证和中等难度任务；开放式奖励必须多 rubric、对图像可见并由独立人工/私有评测校准。

### D9：静态 VLM 与 Agent 系统分开报结果

crop/zoom/OCR/code/search/GUI 能力有价值，但工具次数、额外 token 和环境成本必须单独核算。

### D10：反事实视觉依赖和污染审计进入发布门槛

无图/错图/遮挡测试、图文联合去重和动态私有测试是 SOTA 声明的必要证据。

## 2. 哪些还不是业界共识

| 问题 | 当前观察 | 结论状态 |
|---|---|---|
| 最佳融合范式 | 连续 token 早融合最常见；cross-attention/离散 token 各有优势 | 无全局赢家 |
| 最佳 ViT:LLM 参数比 | 随模型规模、视觉 token 和任务变化 | 未决 |
| 纯文本比例 | 各项目差异显著 | 必须实证 |
| Connector 是否需要独立 warm-up | 独立骨干常用，原生联合可省 | 条件性 |
| 最佳视觉压缩率 | OCR/grounding 与通用 VQA 需求不同 | 必须画曲线 |
| 多层视觉注入 | 多个模型报告有效，但等算力因果证据有限 | 值得优先消融 |
| 视频何时加入 | 早期共享表征有益，过早长视频成本高 | 需要 curriculum |
| 全参数 SFT vs PEFT | 全参数上限更可信，PEFT 成本更低 | 预算相关 |
| CoT 数据比例 | 小模型可能因过多 CoT 退化 | 规模相关 |
| 离线/在线 RL 算力分配 | 级联方案有证据，无统一比例 | 未决 |
| early-joint 是否普遍优于 late adaptation | 超大规模有支持，小模型缺严格比较 | 未决 |

## 3. 风险登记

| 风险 | 影响 | 早期信号 | 研究上的应对 |
|---|---|---|---|
| 把 Stage 0 当完整 L0 | 根本性低估训练范围 | 只有 connector loss/checkpoint | 用 P0–P10 完整性审计 |
| SOTA 目标不受约束 | 永远无法验收 | 基线/推理预算不断变化 | 冻结 capability contract |
| 语言先验伪装视觉能力 | 榜单虚高 | 无图/错图分数接近原分数 | 四路反事实评测 |
| 训练/评测污染 | 私榜崩溃 | 公榜异常高、近重复多 | 图像+文本联合去重和动态集 |
| 视觉 token 粗暴堆量 | 成本失控 | 分数随 token 升但效率恶化 | Pareto 曲线与动态压缩 |
| ViT 冻结造成视觉上限 | OCR/grounding 长期不升 | LLM 变强但定位不变 | 视觉 probing 与解冻对照 |
| 多模态灾难性遗忘 | 文本/代码/数学退化 | text eval 持续下降 | replay、分组 LR、回归门禁 |
| 数据混合被长任务支配 | 能力偏科 | 长 caption/video 梯度占比过高 | 分域采样 + 长度归一化 |
| 合成数据风格坍缩 | 回答模板化、幻觉同质 | teacher 风格可识别 | 多教师、程序核验、人工锚点 |
| 长上下文扩展伤短任务 | caption/单图下降 | P5 后短任务回归 | 旧分布 replay、分阶段门禁 |
| CoT 长度投机 | token 暴涨无准确率增益 | reward 与长度强相关 | thinking toggle、长度惩罚、过程验证 |
| Reward hacking | RL reward 升、真实质量不升 | 私有/人工指标背离 | 多 rubric、独立 judge、对抗审计 |
| Agent 能力掩盖 base 弱 | 工具版强、裸模型弱 | 去工具性能骤降 | base/agent 分表和成本对齐 |
| 超大模型规律误用到小模型 | 预算浪费、能力下降 | token/CoT/ViT 扩大无收益 | 多规模 scaling pilot |

## 4. 模型绑定前必须回答的问题

### 能力与预算

1. 对标的是 1B、3B、7B 还是 MoE active-parameter 档？
2. OCR/文档、视频、GUI、视觉推理中哪些是硬门槛？
3. 允许多少视觉 token、思维 token、工具次数和时延？
4. “SOTA”对比允许使用私有数据/强教师/在线环境吗？

### 初始化与架构

5. ViT 在目标专项 probing 上是否已保留足够信息？
6. LLM 的 tokenizer、位置编码和 context 能否容纳高视觉 token？
7. 选择 post-hoc 全参数联合还是有条件从更早期 checkpoint 做 early-joint？
8. 图像/视频共享编码器还是独立时序模块？

### 数据

9. 可合法使用和再分发的数据边界是什么？
10. 教师模型、合成 token 和人工标注预算是多少？
11. 训练数据如何与公开/私有评测做图文联合去重？
12. 纯文本 replay 的知识、代码、数学目标怎样定门槛？

### 后训练

13. thinking/non-thinking 是两个 checkpoint、mode token 还是自动路由？
14. 哪些任务有可靠可验证 reward？
15. 工具调用是否属于模型交付，环境能否安全复现？
16. 人类偏好和安全审核能覆盖哪些语言/场景？

## 5. 后续调研优先级

本轮已经建立方法骨架。下一轮纯调研最有价值的方向，按顺序是：

1. **分规模研究**：专门比较 1B/3B/7B 的 ViT 大小、视觉 token、CoT 和蒸馏规律。
2. **数据配方深挖**：逐篇提取公开报告的数据桶、token、阶段、过滤和损失权重，形成可比较表。
3. **算力/缩放模型**：不在本地训练，但估算不同路线的 token/FLOPs/存储/教师生成成本与阶段占比。
4. **评测协议落表**：为每个能力域选择公共基准、私有构造方法、反事实测试和推理预算。
5. **后训练专题**：拆解 VLM 蒸馏、DPO/MPO、GSPO/GRPO、视觉 reward 和 Agent 环境。
6. **最后才做模型绑定**：拿具体 ViT/LLM 的结构、tokenizer、上下文和 checkpoint 对照方法骨架，形成 gap analysis。
