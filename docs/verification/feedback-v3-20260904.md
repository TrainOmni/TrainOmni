# v3 feedback closure — 2026-09-04

## Scope and result

This is a current-tree, single-GPU engineering validation of all locally
testable items in `handoff/feedback/20260903-framework-v3.md`, not a throughput
or quality claim. The original feedback file was not modified. The Linux
2x8-L40/HAMI/NCCL worker SIGSEGV root cause cannot be reproduced on this Windows
host and is explicitly still unverified; Framework no longer silently relies on
platform fork and now fails bounded/actionably when a spawned worker dies.

The replacement real task uses:

```text
pretrained Qwen3.5 raw ViT (768)
  -> fresh full Qwen3.5 PatchMerger
     LN(768) -> 2x2/3072 -> Linear 3072x3072 -> GELU -> Linear 3072x1536
  -> pretrained MiniCPM5-1B LLM
```

The 147 raw ViT tensors are bit-equal to the Qwen checkpoint. Every pretrained
Qwen merger tensor is excluded; its `linear_fc1` is proven different from the
new seeded connector. There is no extra one-layer projection. Old tasks and the
generic Framework linear connector remain untouched.

Additionally, BF16 dense packed SDPA exposed an additive-mask cast overflow;
the Transformers language boundary now casts finite FP32 mask sentinels to the
embedding dtype's finite range while preserving boolean masks. Real B=2 BF16
SDPA train/update passes. The strict packing semantic oracle is FP32 because
BF16 changes GEMM shapes between packed and separate calls and is not expected
to be numerically exact; BF16 is instead checked for finite execution and exact
cross-sample isolation.

materialized with local paths, and independently executed through worker0/1/2,
checkpoint, held-out evaluation, export, strict reload and fresh forward. This
proves the delivered files are the tested task rather than approximate prose.
