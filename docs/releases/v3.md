# v3 — data loading and padding-free verification

Git tag: `v3` (annotated). Release branch: `codex/framework-v3-20260903`.
Python package version: `0.1.2`, not `3.0`.

This is the current Framework-only source snapshot, based on correctness commit
`4dacc0d104c91ef88609d90200a5cc99c064e74c`, whose parent is Git v2/main commit
`ced8cf83b9df044d71bcd7916de54b815ea34aed`. The v1/v2 tags and main branch are not
updated by this release. The old correctness report is retained as historical
evidence; v3 additionally includes the new loader and attention/data route.

## Included

- Data configuration, identities, mask/shape/dtype and restore correctness fixes.
- Native PyArrow Parquet/Arrow readers and ms-swift row adapter.
- TorchData StatefulDataLoader, worker-side processing, physical sharding before
  I/O, bounded prefetch, explicit exhaustion and worker-state continuation.
- Fixed-length sequence packing plus a separate padding-free packer/collator.
- Optional xFormers CUTLASS variable-length attention with a narrow Transformers
  Llama integration; no reimplementation of CUDA attention kernels.
- Current source tests, integration/probe scripts, contracts and evidence docs.

## Verification / limits

- Current source full suite: **317 passed, 1 expected Windows/POSIX skip**.
  CUDA varlen tests execute; optional backend skips on an unprepared deployment
  must not be interpreted as evidence that the deployment supports that backend.
- Ruff and whitespace checks pass; 43 builtin descriptors and CLI help work.
- Real pinned Qwen3.5 Vision + MiniCPM5-1B probe: two BF16 connector optimizer
  updates; 537 post-fusion LM tokens, zero padding and no dense LM mask;
  numerical/gradient oracle and exact cross-sample isolation pass.
- [Data/packing evidence](../verification/local-packing-20260903.md),
  [padding-free evidence](../verification/padding-free-20260903.md), and
  [authoritative support matrix](../verification/support-matrix.md).

The new padding-free route is opt-in and model-specific, not FlashAttention,
generic VLM support, a throughput/quality claim, or a new CLI/checkpoint/resume
acceptance. xFormers is optional, lazy-imported and must match the deployment;
the current Windows environment verifies its CUTLASS/aten route only. This
release neither installs nor upgrades Torch or external environments.

## Repository boundary

Framework contents are flattened at the TrainOmni repository root. Runs,
caches, environments, model/data payloads, and the separate FrameworkValidation,
VLMTraining, Research, Downloads and handoff trees are excluded. The real-model
probe takes `--fixtures` to use a separately supplied read-only local fixture
project; those fixtures/checkpoints are not bundled here.

The release is prepared with a temporary Git index and checked in an isolated
worktree, without switching/staging/resetting the shared project checkout. The
existing pre-padding-free wheel documented in STATUS is historical; source
checkout at `v3` is the authoritative content of this Git release.
